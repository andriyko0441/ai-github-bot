# AI-находки с GitHub — бот для Telegram-канала

Бот каждый день сам находит свежие AI-инструменты на GitHub, проверяет их на признаки фейка или вируса, пишет пост на русском, делает креатив и присылает тебе черновики. Ты нажимаешь ✅ или ❌, одобренные посты выходят в канал в 09:00, 14:00 и 20:00 (по Мадриду).

Стоимость: **0 €**. Работает на GitHub Actions, Gemini API (бесплатный тариф) и Telegram Bot API.

---

## Настройка (~30 минут, один раз)

### 1. Канал
Telegram → «Новый канал» → публичный → придумай ссылку, например `@ai_github_finds`.

### 2. Бот
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → получишь **токен** вида `123456:ABC...`.
2. Добавь бота в канал **администратором** с правом «Публикация сообщений».
3. Открой своего бота и нажми **Start**. Без этого он не сможет писать тебе черновики.

### 3. Твой Telegram ID
Напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число `Id`. Это `TELEGRAM_ADMIN_ID`.

### 4. Ключ Gemini (бесплатно, без карты)
[aistudio.google.com](https://aistudio.google.com) → **Get API key** → **Create API key** → скопируй.

### 5. Репозиторий на GitHub
1. github.com → **New repository** → имя `ai-github-bot` → **Public** → Create.
2. **uploading an existing file** → перетащи все файлы и папки из архива (`bot.py`, `config.py`, `templates`, `data` и т.д.) → Commit.
3. Папку `.github` Finder на Mac скрывает, поэтому её создаём вручную: **Add file → Create new file** → в поле имени впиши `.github/workflows/bot.yml` → вставь содержимое файла `bot.yml` из архива → Commit.

### 6. Секреты
**Settings → Secrets and variables → Actions → New repository secret**. Добавь четыре:

| Name | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL` | `@ссылка_канала` |
| `TELEGRAM_ADMIN_ID` | число от @userinfobot |
| `GEMINI_API_KEY` | ключ Gemini |

### 7. Разрешить боту сохранять состояние
**Settings → Actions → General → Workflow permissions → Read and write permissions → Save.**

### 8. Первый запуск
**Actions → ai-github-bot → Run workflow → action: `prepare` → Run.**
Через 3–6 минут в личку от бота придут черновики. Дальше всё работает само каждый день.

## Как пользоваться

- **21:00** — бот присылает 4 черновика на завтра (3 основных + запасной) с кнопками ✅ / ❌.
- **09:00 / 14:00 / 20:00** — выходит по одному одобренному посту.
- Кнопка срабатывает **при следующем запуске бота** (он просыпается раз в час), это нормально.
- Команды боту: `/status` показывает очередь, `/prepare` готовит новые черновики, если все не понравились.
- Время запуска иногда съезжает на 5–30 минут: так GitHub работает на бесплатном тарифе.

### Полный автопилот (без одобрения)
**Settings → Secrets and variables → Actions → вкладка Variables → New variable**:
`AUTO_APPROVE_AFTER_HOURS` = `3`. Тогда черновик, на который ты не ответил за 3 часа, опубликуется сам. Черновики с пометкой ⚠️ сами не публикуются никогда.

### Что можно менять в `config.py`
- `PREPARE_TIME`, `PUBLISH_TIMES` — расписание.
- `SEARCH_TOPICS` — темы поиска (ниша).
- `BANNED_WORDS`, `MIN_OWNER_AGE_DAYS` и др. — строгость фильтра безопасности.

## Как устроено
| Файл | Что делает |
|---|---|
| `github_source.py` | ищет проекты и отсеивает подозрительные (новый аккаунт автора, нет кода или лицензии, пароли к архивам, файлообменники, стоп-слова) |
| `writer.py` | Gemini выбирает самые интересные проекты и пишет пост |
| `render.py` + `templates/card.html` | креатив 1080×1350 |
| `bot.py` | черновики, кнопки, расписание публикаций |
| `data/` | что уже опубликовано (бот сам обновляет) |
